# AIDirectoryHub

AIDirectoryHub is a modern, curated directory of the best AI tools and resources, designed to help users discover, innovate, and create with the power of artificial intelligence. The platform features a clean, app-store-like design with a focus on user experience.

## Features

- **Modern UI**: An app store-inspired design that's intuitive and visually appealing.
- **Curated List of AI Tools**: A collection of the latest and greatest AI applications, loaded from a local JSON file.
- **Category Filtering**: Users can filter tools by categories like Text, Video, Code, and more.
- **Live Search**: Instantly search for any AI tool in the directory with search suggestions.
- **Featured Tool Section**: Highlights a random tool on the homepage to promote discovery.
- **"Load More" Functionality**: Improves initial page load speed by showing a limited number of tools and loading more on demand.
- **Multi-language Support**: Content is available in both English and Spanish, managed through JSON locale files.
- **Donation Page**: A dedicated page for users to support the project via Buy Me a Coffee or JazzCash QR code.
- **Supporters Showcase**: Publicly thanks supporters by listing their names on the donation page.
- **SEO Optimized**: Includes meta tags and Open Graph data for better search engine visibility and social sharing.
- **Monetization Ready**: Integrated support for Google AdSense banners and affiliate links.
- **Responsive Design**: Fully responsive layout that works on desktops, tablets, and mobile devices.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [ShadCN UI](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Linting & Formatting**: ESLint and Prettier (defaults in Next.js)

## Getting Started

To get started with this project, you can run it locally using the following commands:

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Run the development server:**
    ```bash
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the main page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.
